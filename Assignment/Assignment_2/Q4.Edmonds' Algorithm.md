# Edmonds' Algorithm

### State the problem solved by Edmonds' Algorithm in precise terms.

Edmonds' Algorithm solves the Maximum Cardinality Matching problem in general graphs.

In precise terms, it finds the largest possible set of edges such that no two edges share a common vertex, meaning each vertex is matched with at most one other vertex.

Unlike algorithms that only work on bipartite graphs, Edmonds' Algorithm works on any graph, including those with odd-length cycles.
