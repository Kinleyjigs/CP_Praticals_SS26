# Johnson's Algorithm 

#### a.Explain why Johnson's Algorithm is more efficient than Floyd-Warshall for sparse graphs.
Floyd-Warshall always takes O(V³) time because it checks all possible vertex combinations, even if many edges don't exist.

Johnson's Algorithm is faster for sparse graphs because it only works with the actual edges. Its complexity is O(VE + V² log V), which is much better when edges are few.

So in short Floyd-Warshall wastes time on non-existing edges whereas Johnson's algorithm focuses only on real edges  more efficient

#### b.Describe the purpose of edge reweighting and how Bellman-Ford is used in this context.

Dijkstra's algorithm is fast but cannot handle negative weights.
Johnson's fixes this using edge reweighting.

#### Purpose of Reweighting
It changes edge weights so that:
- All weights become non-negative
- Shortest paths still remain the same

#### Role of Bellman-Ford
Bellman-Ford is used at the start to:
1. Add a temporary source node
2. Compute shortest distances to all vertices
3. Detect negative cycles 

These distances are then used to **adjust edge weights**, making them safe for Dijkstra.
